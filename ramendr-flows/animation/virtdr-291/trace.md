## Ordered upstream source trace

Delegated as required by flow-animation. SHAs are explanatory evidence, not deployed-build provenance (the deployed driver image `quay.io/openshift-virtualization-dr/csi-powerstore:20260805143521` source commit was not established).

Ramen base: `https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller`

1. **Failover entry.** `RunFailover` checks `failoverCluster`, calls `isValidFailoverTarget` (target VRG Primary, or Secondary with observedGeneration == generation, read through the ManagedClusterView), then `switchToFailoverCluster`, which sets `FailingOver`, PeerReady False, retains the source decision and calls `switchToCluster`. [drplacementcontrol.go#L430-L509](https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller/drplacementcontrol.go#L430-L509), [#L566-L593](https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller/drplacementcontrol.go#L566-L593), [#L621-L681](https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller/drplacementcontrol.go#L621-L681).
2. **Discovered app.** `isDiscoveredApp` is true when `protectedNamespaces` is set; the namespaces are copied into the VRG spec. ManifestWork name format `%s-%s-%s-mw` (DRPC, VRG namespace, type) matches the live `hammerdb-drpc-openshift-dr-ops-vrg-mw`. [#L1074-L1076](https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller/drplacementcontrol.go#L1074-L1076), [util/mw_util.go#L36-L79](https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller/util/mw_util.go#L36-L79). The VRG ownerReference in the role-evidence JSON carries a hash-prefixed ManifestWork name; only the live, unprefixed names are shown on screen. UNVERIFIED: origin of that prefix.
3. **WaitingForResourceRestore** is set in `switchToCluster` after the Primary VRG ManifestWork update and while target readiness is false; placement is updated only after readiness. [#L1470-L1495](https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller/drplacementcontrol.go#L1470-L1495).
4. **Target VRG Primary.** `processAsPrimary` runs `clusterDataRestore` (PV/PVC from S3, handle substitution), waits for DataReady, then `kubeObjectsRecover` and sets `KubeObjectsReady`. Velero Restore requests use the protected namespaces as `IncludedNamespaces`. [volumereplicationgroup_controller.go#L1497-L1550](https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller/volumereplicationgroup_controller.go#L1497-L1550), [vrg_kubeobjects.go#L736-L880](https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller/vrg_kubeobjects.go#L736-L880), [kubeobjects/velero/requests.go#L191-L200](https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller/kubeobjects/velero/requests.go#L191-L200). UNVERIFIED: CDI adoption mechanics that made restored DataVolumes report Succeeded on existing claims (outcome recorded).
5. **Promote.** csi-addons `markVolumeAsPrimary` retries with Force on known errors; PowerStore `PromoteVolume` maps forced promote to an unplanned failover (`RsActionFailover`). [csi-addons#L608-L640](https://github.com/csi-addons/kubernetes-csi-addons/blob/eca6e16ba6a5f68a04a10591dc587e4b48132743/internal/controller/replication.storage/volumereplication_controller.go#L608-L640), [csi-powerstore#L867-L1020](https://github.com/dell/csi-powerstore/blob/c35ca28883044f240bab36d47e43da3f96f080cd/pkg/controller/csiaddons_replication.go#L867-L1020). Original volume becoming a read-only destination is recorded by the array (`is_replication_destination: true`, session role Destination), not derived from driver code.
6. **Source pause.** KubeVirt `setErrorPolicy` defaults disks to `stop`; `calculatePausedCondition` maps an IOError pause to `PausedIOError`, "VMI was paused, low-level IO error detected". [disk.go#L74-L86](https://github.com/kubevirt/kubevirt/blob/4717f10d96cfb0dab5898a1fd3996fbc61686f40/pkg/virt-launcher/virtwrap/converter/storage/disk.go#L74-L86), [vm.go#L1089-L1126](https://github.com/kubevirt/kubevirt/blob/4717f10d96cfb0dab5898a1fd3996fbc61686f40/pkg/virt-handler/vm.go#L1089-L1126).
7. **WaitOnUserToCleanUp.** `setDiscoveredAppGCProgression` sets it for discovered apps without automatic VM cleanup; called from `cleanupSecondary`. [#L3209-L3232](https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller/drplacementcontrol.go#L3209-L3232), [#L2427-L2440](https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller/drplacementcontrol.go#L2427-L2440).
8. **Disuse gate and demotion.** `isPVCInUse` blocks Secondary while a pod references the claim or a VolumeAttachment exists; csi-addons Demote then Resync; PowerStore `DemoteVolume` runs Reprotect on a Failed_Over session, reversing direction. [vrg_volrep.go#L297-L360](https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller/vrg_volrep.go#L297-L360), [csi-addons#L360-L390](https://github.com/csi-addons/kubernetes-csi-addons/blob/eca6e16ba6a5f68a04a10591dc587e4b48132743/internal/controller/replication.storage/volumereplication_controller.go#L360-L390), [csi-powerstore#L1174-L1184](https://github.com/dell/csi-powerstore/blob/c35ca28883044f240bab36d47e43da3f96f080cd/pkg/controller/csiaddons_replication.go#L1174-L1184).
9. **Placement and completion.** `createOrUpdatePlacementDecision` keeps retained decisions and appends the target; `cleanupSecondary` removes the retained source decision after the source VRG accepts Secondary; `ensureActionTransition` sets `Completed`; PeerReady True after peers report Secondary. [drplacementcontrol_controller.go#L2074-L2110](https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller/drplacementcontrol_controller.go#L2074-L2110), [drplacementcontrol.go#L2321-L2445](https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller/drplacementcontrol.go#L2321-L2445), [#L1078-L1103](https://github.com/RamenDR/ramen/blob/4191ad115cd48701b2f2fb95b5f623db773bc702/internal/controller/drplacementcontrol.go#L1078-L1103). The retained-decision reason string differs between Ramen revisions, so the video does not show it verbatim.
