🔀 Traffic Flows

👑 Management Plane

1.Hub API (edge36) exposes TCP 6443 via socat
2.edge97 DNS resolves hub API to 10.46.46.12
3.Klusterlet on Spoke 2 connects to Hub
4.ACM manages both spokes from Hub

🔒 Submariner Data Plane

1.Gateway nodes selected (1 per spoke)
2.Public IP annotation: hypervisor corp IP
3.IPsec tunnel via UDP 4500 (NAT traversal)
4.Globalnet assigns virtual IPs (CIDR overlap)
5.Cross-cluster service discovery via .clusterset.local

💾 Storage / DR Plane

1.Dell VSAs deployed on eco-vCenter (Tzach)
2.Spokes connect to VSAs via iSCSI (NAT to corp net)
3.VSA-A replicates async to VSA-B (Dell native)
4.RamenDR orchestrates failover via Submariner
5.S3 metadata store for DR coordination
